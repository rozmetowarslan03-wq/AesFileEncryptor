# AES-256-GCM Файл Шифрлағышы (JCA)

**Орындаған:** Розметов Арслан  
**Пән:** Ақпараттық қауіпсіздік / Java криптографиясы (№8 жоба — Орта деңгей)  
**Технологиялар:** Java 21+, Maven, JCA (`javax.crypto`, `java.security`), JUnit 5

---

## 1. Жобаның мақсаты
Бұл утилита стандартты **Java Cryptography Architecture (JCA)** құралдарын пайдалана отырып, пайдаланушының құпиясөзінен (парольден) криптографиялық тұрғыда берік 256-биттік кілт өндіруге және кез келген көлемдегі файлдарды **AES-256-GCM** алгоритмімен қауіпсіз шифрлау мен дешифрлауға арналған.

Жүйе тек деректердің құпиялылығын (confidentiality) ғана емес, сонымен қатар олардың **тұтастығы мен түпнұсқалығын (integrity & authenticity)** қамтамасыз етеді.

---

## 2. Криптографиялық архитектура және ерекшеліктері
Жобада өздігінен ойлап табылған алгоритмдер қолданылмаған, барлық операциялар ресми стандарттарға негізделген:

* **Кілт генерациясы (Key Derivation Function):** `PBKDF2WithHmacSHA256` алгоритмі қолданылады. Brute-force шабуылдарынан қорғау үшін **65 536 итерация** және әр шифрлау сайын `SecureRandom` арқылы генерацияланатын **16-байттық (128 бит) кездейсоқ `salt`** пайдаланылады.
* **Аутентификацияланған шифрлау (AEAD):** `AES/GCM/NoPadding` режимі қолданылады. Әрбір операция үшін бірегей **12-байттық (96 бит) кездейсоқ `IV` (Initialization Vector)** жасалады және деректердің өзгермегенін растайтын **128-биттік GCM аутентификация тегі** есептеледі.
* **Үлкен файлдарды бөліп өңдеу (Streaming / Chunking):** Файлды жедел жадыға (RAM) толық жүктемей, `CipherInputStream` және `CipherOutputStream` ағындары арқылы **8 КБ (8192 байт)** буфермен бөліп өңдейді. Бұл гигабайттық файлдарды да жады жетіспеушілігінсіз (OutOfMemoryError) шифрлауға мүмкіндік береді.
* **Бұрмалауды және қате паролді анықтау:** Егер дешифрлау кезінде қате құпиясөз енгізілсе немесе шифрланған `.enc` файлының ішіндегі бір ғана байт өзгертілсе, GCM тегі сәйкес келмей қалады да, жүйе `AEADBadTagException` қатесін беріп, файлды ашудан бас тартады.

## 3. Шифрланған файлдың ішкі құрылымы (`.enc`)
Дешифрлау кезінде бағдарлама бастапқы параметрлерді дұрыс оқуы үшін шығыс `.enc` файлы мынадай бинарлық құрылыммен жазылады:

| Бөлім | Көлемі | Сипаттамасы |
| :--- | :--- | :--- |
| **1. Salt** | 16 байт | PBKDF2 кілтін қайта есептеуге арналған кездейсоқ мән |
| **2. IV (Nonce)** | 12 байт | AES-GCM шифрлау режимінің инициализация векторы |
| **3. Ciphertext + GCM Tag** | Айнымалы + 16 байт | Шифрланған негізгі деректер және 128-биттік тұтастық тегі |

## 4. Орнату және іске қосу нұсқаулығы

1. **Репозиторийді клондау:**
   ```bash
   git clone https://github.com
   cd AesFileEncryptor
   ```

2. **Жобаны жинақтау және JUnit 5 тестілерін іске қосу (10 тест):**
   ```bash
   mvn test
   ```

3. **Консольдік қосымшаны іске қосу:**
   ```bash
   mvn compile exec:java -Dexec.mainClass="kz.vault.AesFileEncryptor"
   ```

## 5. Қолдану мысалы және жұмыс нәтижесі
Бағдарлама іске қосылғанда пайдаланушыға интерактивті мәзір ұсынылады:
1. **`1` — Мәтінді жазып шифрлау:** Мәтін мен құпиясөз енгізіледі, нәтижесінде `secret_data.txt.enc` файлы құрылады.
2. **`2` — Шифрланған файлды дешифрлау:** Пайдаланушы құпиясөзді қайта енгізеді. Дұрыс пароль енгізілсе бастапқы мәтін `secret_data_decrypted.txt` файлына қалпына келтіріледі, ал қате пароль енгізілсе қауіпсіздік қатесі шығады.

## 6. Тестілеу (JUnit 5)
`AesFileEncryptorTest` класында жобаның барлық негізгі және шекті сценарийлерін тексеретін **10 автоматтандырылған тест** жазылған:
* 256-биттік кілт ұзындығы мен `AES` алгоритмін тексеру;
* Бірдей және әртүрлі `salt` мәндерінің кілт генерациясына әсері;
* Мәтіндік файлдарды сәтті шифрлау және дешифрлау;
* Шифрланған файлдың бастапқы деректерден толық өзгеше болуы;
* Қате құпиясөз енгізгенде дешифрлауды бұғаттау;
* Шифрланған файлдың байттары бүлінгенде тұтастық қатесін беру;
* Үлкен көлемді (2 МБ) файлдарды буфермен бөліп өңдеу;
* Бос файлдарды және тақырыбы бүлінген файлдарды өңдеу.

## 7. Қауіпсіздік ескертпесі
* **Құпия файлдарды оқшаулау:** Шифрланған файлдар (`*.enc`), кілттер (`*.key`), `.env` және құпия мәтіндер (`secret_data*.txt`) `.gitignore` файлы арқылы Git бақылауынан алынып тасталған.
* **Жедел жадыны тазалау:** Құпиясөздер жадыда ұзақ сақталатын `String` типінде емес, `char[]` массивінде өңделеді және шифрлау/дешифрлау аяқталған бойда `Arrays.fill(password, '\0')` әдісімен нөлдермен толтырылып өшіріледі.
